## 本轮定位并修复的问题

1. 原来的默认模拟回显不能满足真实业务：安装真实模型与CPU运行时，默认配置改为真实后端；mock保留在单独配置中。
2. 中文“退出”没有结束会话：增加退出别名；算术用受限计算器得到确定结果。
3. 官方视觉示例的动态数组、输出尺寸和资源释放不够稳健：原生适配器使用边界检查与堆缓冲区，并用测试替身验证错误路径。
4. Windows Vosk原生库无法读取含中文的绝对模型路径：只在隔离的识别子进程内切换工作目录，使用ASCII模型目录名；不改系统编码。
5. HTTP请求不能及时停止：改为受控工作进程，取消时终止本次请求并关闭连接。
6. GUI关闭时工作线程可能仍创建模型进程：先取消并等待本次工作退出，再关闭本窗口拥有的服务。
7. 下载中断/重复解压可能损坏文件：使用临时文件、大小与SHA256验证、路径检查，拒绝覆盖不同的已有文件。
8. 告警截图和输入路径：限定目录、拒绝越界，PPM转换PNG后送入视觉模型。
