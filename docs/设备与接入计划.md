# 设备与接入计划

2026-09-15 更新：电脑端真实语言/视觉模型与语音文件链路已经验证。部署现状以[部署与到货验收](部署与到货验收.md)为准；下表为设备对应关系，不能代替板端测试记录。

用户提供：RK3588 16GB + 32GB eMMC、12V原装电源、风扇、32GB A2 microSD、千兆网线、1080p UVC USB摄像头、USB麦克风、音箱/耳机，各1件。

| 设备 | 代码对应 | 到货后验收 |
|---|---|---|
| RK3588 16GB | RKLLM/RKNN原生后端、Linux CPU后端、单请求调度 | 厂商系统启动、运行时版本匹配、官方模型能推理；记录内存/温度/响应时间 |
| 32GB eMMC | 系统、程序、单组模型 | 核对剩余空间，不把标称容量当可用容量；预留日志和系统更新空间 |
| 12V原装电源 | 无软件替代 | 核对具体板卡输入电压、电流、极性和接口，不能将12V用于不支持的接口 |
| 风扇 | 后续按厂商驱动监测 | 长时间推理不因散热不足降频；当前代码不假设GPIO引脚或改变风扇控制 |
| 32GB microSD A2 | 可用于镜像恢复或数据 | 与板卡启动方式匹配；当前不格式化、不刷写任何介质 |
| 千兆网线 | 部署、调试、局域网告警 | 本项目模型服务默认本机回环；离线不等于不能使用局域网 |
| 1080p UVC摄像头 | capture命令、FFmpeg | 先640×480单帧，再提高分辨率；检查设备是否支持请求格式，避免与项目一抢占 |
| USB麦克风 | record、Vosk | 清晰5秒录音、16kHz单声道识别；不常驻监听 |
| 音箱/耳机 | speak、espeak-ng | 验证ALSA/系统默认输出、中文播放；完整语音链路后再做回声消除 |

当前下一步：取得官方配套NPU模型 → 目标Linux构建 → 外设接入与NPU验证 → 性能与长期运行。电脑端不再只提供Mock演示。

当前不需要训练自己的大模型，也不需要同时运行多个大模型。16GB内存不是无限预算；上下文、量化方式、视觉编码器和KV缓存共同占用内存，最终以板端测量为准。

仍需确定：具体开发板型号与Linux镜像、SDK/驱动版本、模型及量化产物、真实音频设备名。未知项不会在代码中伪装为已完成。
