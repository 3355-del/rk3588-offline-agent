# 2026-10-30 板卡原始 CLI 运行

平台：Orange Pi 5 / RK3588S，Ubuntu，内核 6.1.99-rockchip-rk3588。

实际运行命令：

```sh
bash scripts/run_linux.sh --npu chat
```

原始 CLI 显示 backend=rkllm_native。实际问题和回答：

```text
你：请用一句话说明NPU的用途。
助手：NPU（神经网络处理单元）用于在设备端高效执行深度学习模型推理任务，以实现低延迟、高效率的数据处理。
```

为在无显示器板卡上截图，本次用一个仅监听电脑回环的临时网页终端转发 SSH PTY 输入输出。截图直接取自这个实时终端；它不是项目自带 GUI，不承诺仓库提供该临时截图工具。不是根据历史 JSON 重新绘制问答内容。原始 CLI 代码没有为截图改写。

同晚另一次原始 CLI 执行的退出码为 0，退出后原生 worker 已释放；截图会话也使用 /quit 正常退出。两个项目按顺序使用 NPU，不并行。

本轮未启动语音外设；摄像头现场很暗，因此没有把无可辨识物体的画面作为视觉准确性示例。此截图不能证明视觉/语音准确率、通用延迟或长稳结果。
