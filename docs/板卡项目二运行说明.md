# 板卡项目二运行说明

> 日常启动请使用 [新版完整操作手册](操作手册-启动与板卡交互.md)。下文保留早期部署记录，设备枚举、测试库路径和待验状态不代表当前配置；最新状态见 [2026-10-04 接手清单](最新交接记录.md)。

部署目录：`/path/to/project`，SSH：`root@YOUR_BOARD_IP`。实际板卡：Orange Pi 5，ARM64，约8GB内存。

## 当前测试入口

电脑双击项目根目录 `打开板卡项目二测试.cmd`，出现中文菜单后选择文本对话、语音问答、拍照描述、告警查询、播放测试或自检。启动菜单本身不录音、不拍照；选中对应动作才使用设备。

板卡本地执行：

```bash
cd /path/to/project
bash scripts/board_console.sh
# 或直接运行
bash scripts/run_linux.sh --cpu chat
bash scripts/run_linux.sh --cpu ask '你好，请用中文回答'
bash scripts/run_linux.sh --cpu voice-once
bash scripts/run_linux.sh --cpu alarms --limit 5
```

CPU与NPU真实模型均已部署。NPU入口为项目根目录的 打开板卡项目二NPU测试.cmd，板卡执行 bash scripts/board_console.sh --npu。NPU菜单及聊天在同一进程内复用模型，首次请求加载语言模型，首次看图加载视觉模型；退出窗口释放。取消、超时或SDK错误会释放本次工作进程，下次请求重新加载。

## 音频与摄像头

- 摄像头：`/dev/video0`，项目一占用时须先协调使用，不能默认同时打开。
- USB麦克风：`plughw:CARD=Audio,DEV=0`（AB13X USB Audio），已验证产生16kHz单声道PCM文件。
- `audio_linux` 选择录音输入，`audio_output_linux` 单独选择播放输出。
- 板卡枚举到DP、HDMI和板载ES8388三个播放设备；实际音响接法需要用户确认，不依据设备枚举推断已听到声音。
- Linux语音支持 `tts_linux=espeak` 或可选 `piper`；Piper需要安装 `requirements-linux-voice.txt` 和配套离线模型、JSON配置，缺失时明确报错。
- 本次已启用Piper并通过“合成→识别”验收；`bootstrap_linux.sh`会根据配置安装依赖并调用 `scripts/setup_piper.py` 校验/获取模型。实际音响输出仍等待接线确认。
- 录音、照片只保存在板卡项目 `inputs/`。用户可按需保留，不自动上传到云端。

## 告警联动

本轮使用独立测试库 `/path/to/project/data/integration/alarms.sqlite3`，截图在同目录 `shots/`，没有更改或重跑项目一既有长稳测试。测试记录来自项目一对现有person_h264文件的真实NPU检测，不是模拟事件。

此接收器只在联动验收脚本运行期间启动。若需要持续接收项目一告警，应运行实际接收器，并将两个项目的数据库、截图配置指向同一运行目录；已有测试库不会自动接收后续任何来源的告警。

复现联动：

```bash
cd /path/to/project
.venv-linux/bin/python scripts/check_board_integration.py
```

## 常驻模型使用（2026-10-03）

- 推荐保持同一个NPU菜单窗口：选1对话，聊天内 /quit 返回菜单，菜单0退出并释放模型。
- /reset 或菜单7只清除对话历史，不重新加载权重；每轮SDK KV缓存重新清空，历史由应用显式传递。
- 菜单切换拍照和语音问答也复用同一Agent；不会自动录音、拍照。
- 每次单独运行 ask/voice-once 命令仍是一个独立会话，进程退出会释放模型，不会跨终端偷偷驻留。
- 配置 native_resident=false 可恢复一次性加载模式，用于对比或排障；默认true。
- 常驻视觉与语言模型会保持内存占用，不等于空闲时释放。不要同时打开多个推理会话，避免重复加载占满板卡内存。
- 同参数对比及生命周期验收：.venv-linux/bin/python scripts/check_resident_board.py --seconds 180。

常驻板卡实测通过：后续两字问候中位0.489秒、合成图识别4.399秒；首次加载更慢，不是任意问题的固定耗时。197次混合请求约3分钟，模型进程稳态约3.08GiB，取消/超时恢复及退出释放通过。证据与完整边界见验收清单。
